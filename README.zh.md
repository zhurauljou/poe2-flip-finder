# PoE 2 Flip Finder

[English](README.md) · [Русский](README.ru.md) · **中文**

在 **《流放之路 2》** 货币交易所（阿尔瓦）中查找能盈利的货币兑换路径。

程序读取 GGG 官方的每小时真实成交数据，寻找能带来利润的兑换链——例如 `Divine → Chaos → X → Divine`。
程序在你的电脑上、在浏览器中运行。

## 下载

**[⬇ 最新版本 — poe2-flip.zip](https://github.com/zhurauljou/poe2-flip-finder/releases/latest)**

解压后按照 `How to start.txt` 操作。简而言之——只需运行一个文件：

- **Windows：** 需要 [Python 3.8+](https://www.python.org/downloads/)（安装时勾选“Add python.exe to PATH”），然后运行 `Start (Windows).bat`
  （首次运行后旁边会出现带神圣石图标的 **PoE 2 Flip Finder** 快捷方式——之后用它启动即可）。
- **Mac：** 右键点击 `Start (Mac).command` →“打开”。

程序会自动查找更新：有新版本时，顶部会出现“更新”按钮。
手动检查——筛选面板底部的“检查更新”。

## 功能

- **兑换循环和路径**，包含利润、流动性、时间和金币手续费。
- **“持续”**——路径已连续盈利多少小时，以及经过历史验证的**评分**：
  排在最上面的是最常在下一小时仍保持盈利的路径。
- **按交易对波动设置余量**——波动大的交易对余量更大，稳定的更小。
- **步骤面板**：付出什么、获得什么、汇率、24 小时走势；可以填写游戏中的汇率和实际获得的数量。
- **“阿尔瓦”模式**——大字显示，每屏一步（在游戏旁用手机很方便）。
- **交易记录**——你在各交易对上的实际价差。
- 页面和 **Telegram** 中的**提醒**：通过公共机器人 [@PoeFlipperBot](https://t.me/PoeFlipperBot)（高级用户也可使用自己的机器人）。
- **交易对**：起始货币所有交易对的参考——汇率、流动性、挂单、24 小时走势，支持搜索。
- **预设**：“稳健 / 快速 / 高利润”一键切换；已更改的筛选会被标出并可重置。
- **用手机访问**：📱 按钮——开启家庭 Wi-Fi 访问并扫描二维码。
- 浅色/深色主题，Русский / English / 中文。

## 数据与隐私

一切都在本地运行。汇率来自 GGG 官方 API，名称和图标来自 poe.ninja 和 RePoE。
交易记录和 Telegram 机器人令牌只保存在你的电脑上（Windows：`%APPDATA%\poe2-flip`，
Mac：`~/.config/poe2-flip`），不会发送到任何地方。

## 重要

这些是**每小时真实成交的平均汇率**，而不是实时挂单。每次兑换前请在游戏中核对汇率。
不保证盈利。本项目与 Grinding Gear Games 无关。
