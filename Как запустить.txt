PoE 2 Flip Finder 1.0
Поиск выгодных обменов валюты на бирже Path of Exile 2 (у Альвы)

Программа берёт официальные почасовые данные GGG о реальных сделках на бирже и ищет
цепочки обменов, которые приносят прибыль: например, Divine → Chaos → X → Divine.
Работает у вас на компьютере, в браузере. Ничего не устанавливает, кроме Python.

Важно: это СРЕДНИЕ курсы по сделкам за час, а не живой стакан. Перед каждым обменом
сверяйте курс в игре. Никаких гарантий прибыли — используйте на свой страх и риск.
Программа не связана с Grinding Gear Games.


═══ УСТАНОВКА ═══

WINDOWS
1. Распакуйте архив: правый клик по poe2-flip.zip → «Извлечь все». Из самого архива не запускается.
2. Нужен Python 3.8 или новее (бесплатно): https://www.python.org/downloads/
   При установке ОБЯЗАТЕЛЬНО отметьте галочку «Add python.exe to PATH».
3. Запустите «Запустить (Windows).bat». Если Windows покажет «Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае».
4. Откроется браузер с программой. Чёрное окно — это сама программа: не закрывайте его, пока пользуетесь.

MAC
1. Распакуйте архив двойным щелчком.
2. Правый клик по «Запустить (Mac).command» → «Открыть» (в первый раз именно так, потом — двойным щелчком).
3. Если macOS предложит установить инструменты разработчика (для python3) — согласитесь и дождитесь установки.

Первый запуск: программа ~10 секунд скачивает данные за последние сутки, потом всё работает сразу.
Дальше, пока окно открыто, она сама докачивает новые данные каждые 5 минут.


═══ КАК ПОЛЬЗОВАТЬСЯ ═══

Вверху — лига, язык (RU / EN / 中文) и тема. Слева — фильтры (на телефоне — кнопка «Фильтры»).
У каждого поля есть «?» с подсказкой.

Вкладки:
- «Циклы флипа» — найденные пути. Самые надёжные сверху (колонка «Рейтинг»):
  учитывается прибыль, ликвидность и «Держится» — сколько часов подряд путь уже даёт прибыль.
  Чем дольше держится, тем чаще он сохраняется и дальше.
- «Туда-обратно» — пары для простого флипа «купить дешевле — продать дороже».
- «Курсы валюты» — курсы любой валюты.
- «Журнал» — ваши записанные сделки и ваш реальный спред по парам.

Клик по пути открывает панель шагов: что отдать, что получить, курс, ликвидность, тренды за сутки.
Туда можно вписать курс, который видите у Альвы, и сколько реально получили — всё пересчитается.
Кнопка «Режим у Альвы» — крупно, по одному шагу на экран (удобно на телефоне рядом с игрой).
Пройдя путь, нажмите «Записать сделку в журнал».


═══ С ТЕЛЕФОНА ═══
(телефон и компьютер — в одной Wi-Fi сети)

1. На компьютере закройте обычное окно программы и запустите
   «Запустить для телефона (Windows).bat» (на Mac — «Запустить для телефона (Mac).command»).
2. В чёрном окне появится адрес вида http://192.168.x.x:8765/ — откройте его в браузере телефона.
3. Windows при первом запуске спросит про доступ Python к сети — нажмите «Разрешить».
   Если Wi-Fi отмечен как «Общедоступная сеть», переключите на «Частная»:
   Параметры → Сеть и Интернет → Wi-Fi → свойства сети → «Частная сеть».
4. VPN на компьютере может закрывать доступ из домашней сети — отключите его
   или включите в VPN доступ к локальной сети.
Этот режим — для дома: страницу может открыть любое устройство в вашей Wi-Fi сети.


═══ УВЕДОМЛЕНИЯ ═══

На странице: галочка «Уведомлять о новых путях» слева — карточка на странице, звук
и уведомление браузера, когда появляется путь с нужной прибылью и «Держится».

В Telegram (приходят, даже когда браузер закрыт, — но программа должна быть запущена):
1. Включите «Уведомлять о новых путях» — ниже появится блок Telegram.
2. В Telegram откройте @BotFather → /newbot → придумайте имя → скопируйте токен и вставьте в программу.
3. Отправьте своему боту сообщение /link с кодом, который покажет программа.
Другие люди тоже могут пользоваться вашим ботом: дайте им ссылку t.me/имя_бота — они напишут
/start и настроят свои условия кнопками прямо в Telegram. Им не нужна ни программа, ни токен.

Если вам кто-то дал ссылку на своего бота — программа не нужна: просто напишите боту /start.


═══ ГДЕ ХРАНЯТСЯ ДАННЫЕ ═══

- Скачанные курсы — в папке программы, в cache (можно удалить, скачаются заново).
- Журнал сделок, токен Telegram-бота и подписчики — отдельно, в профиле пользователя:
  Windows: %APPDATA%\poe2-flip     Mac: ~/.config/poe2-flip
- Фильтры, избранное и вид страницы — в вашем браузере.
Удалить программу полностью: удалите её папку и папку poe2-flip из профиля (пути выше).


═══ ПЕРЕДАТЬ ПРОГРАММУ ДРУГОМУ ═══

Запустите «Собрать архив для передачи (Windows).bat» (на Mac — «… (Mac).command»)
и отправьте получившийся poe2-flip.zip. В архив попадает только программа —
ваши журнал, токен бота и подписчики не попадают. Не отправляйте папку программы целиком.


═══ ЕСЛИ НЕ РАБОТАЕТ ═══

- Окно сразу закрывается или пишет ошибку — сделайте скриншот чёрного окна.
- «Не найден Python» — установите его (см. выше) с галочкой «Add python.exe to PATH».
- Браузер открылся, но вверху «Ошибка» — нет доступа к сайтам с данными
  (poe.ninja, web.poecdn.com, repoe-fork.github.io): проверьте интернет и VPN.
- Пишет «Сервер уже работает» — программа уже запущена в другом окне; оно и откроется.
