# Как выпустить новую версию

Программа у пользователей раз в 6 часов спрашивает GitHub о последнем релизе
(`zhurauljou/poe2-flip-finder`). Если его номер больше, чем `VERSION` у них, — появляется кнопка «Обновить»,
которая скачивает из релиза файл **`poe2-flip.zip`** и заменяет файлы программы.

1. Поднять номер в `app/server.py`: `VERSION = "1.2"`.
2. Собрать архив: `tools/Build release zip (Windows).bat` → в корне появится `poe2-flip.zip`.
3. Закоммитить и отправить изменения:
   ```
   git add -A
   git commit -m "Версия 1.2: что изменилось"
   git push
   ```
4. На GitHub: **Releases → Draft a new release**
   - Tag: `v1.2` (создать новый, номер — как в `VERSION`)
   - Title: `1.2`
   - Описание — коротко, что нового (пользователи увидят его под «Что нового» перед обновлением)
   - Прикрепить файл **`poe2-flip.zip`** (имя важно)
   - **Publish release**

Через несколько часов (или после перезапуска программы) у всех появится предложение обновиться.

## Структура

- В корне — только то, что нужно человеку: `Start (Windows).bat`, `Start (Mac).command`, `How to start.txt`
  (+ ярлык `PoE 2 Flip Finder.lnk`, который программа создаёт сама при запуске на Windows).
- `app/` — сама программа (и её кэш `app/cache`, не в git).
- `tools/` — только для выпуска релизов, в архив для людей не попадает.

Новые файлы программы нужно добавить в `PACK_FILES` в `app/server.py` — иначе их не будет ни в архиве, ни в обновлении.
